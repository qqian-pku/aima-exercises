

Explain why problem formulation must follow goal formulation.
Problem formulation must follow goal formulation because the purpose of problem formulation is to provide a concrete and operational description of how to achieve a given goal.
The goal specifies what the agent wants to accomplish, while the problem formulation specifies how the agent can achieve it — that is, what actions, states, and constraints are relevant.
Without a clearly defined goal, it would be impossible to decide which aspects of the world should be included or ignored in the problem representation.
For example, if the goal is to find the shortest route from city A to city B, then the problem formulation focuses on distances and possible routes, while irrelevant details such as scenery or local culture are excluded.
